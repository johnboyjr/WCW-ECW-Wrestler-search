WCW MATCH SEARCH ENGINE
=======================

Search every NWA / Jim Crockett Promotions, WCW and ECW match - TV, pay-per-views,
Clash of the Champions, house shows and dark matches - including WWE's ECW brand
(2006-2010). The whole match database comes built into the app.

START
  Install:  double-click Install.cmd (adds Start menu + desktop shortcuts, no admin
            needed; uninstall from Settings > Apps).
  Portable: double-click "WCW Match Search Engine.exe".
  SmartScreen may warn because it isn't code-signed: "More info" > "Run anyway".

ASK IT THINGS
    Hulk Hogan                         every Hogan match + his record on the right
    Hulk Hogan lost                    every match he lost   (or: won, draw)
    Sting vs Ric Flair                 every Sting/Flair match with head to head
    Goldberg beat Hogan                Goldberg's wins over Hogan
    Hulk Hogan never beat Sting or Arn Anderson in a singles match
                                       TRUE / NOT TRUE for each, with the record and
                                       every match they had
    Hogan never beat Sting clean       only pinfalls and submissions count as wins
    Hulk Hogan never beat              everyone Hogan faced and never beat
    Who never beat Ric Flair           everyone who faced Flair and never beat him
    Goldberg never lost to             everyone Goldberg faced and never lost to
    Goldberg never lost                TRUE / NOT TRUE, with every loss listed
                                       (add "in a singles match", "clean" ...)
    Taz never lost to Sabu or RVD      TRUE / NOT TRUE for each
    Goldberg debut / Flair last match  first / last NWA-WCW match in the database
    WarGames, Bunkhouse, Texas bullrope, Scaffold, Tower of Doom, I Quit ...
                                       match types (alone or with a name)
    Hogan DQ run-in                    DQs where the result mentions interference
  The "Never beat... / Never lost to... / Never lost" buttons do the same for whatever
  name is in the box. "never" works with "beat", "lost to", any match type ("in a cage match", "in a
  singles match") and the Clean finish. By default a DQ or count-out win counts as a
  win; choose "Clean (pin / submission)" for only clean wins. On "who never beat"
  lists, "Faced 2+ times" hides one-off matches.

FILTERS
  NWA / Crockett (to Nov 1988), WCW (Nov 1988 - 2001), ECW (1992-2001) and WWE ECW
  (2006-2010) - pick one or several - years, TV / PPV /
  house shows, a single show (Nitro, Thunder, Saturday Night, Worldwide, Clash of the
  Champions, Starrcade, Halloween Havoc, ECW Hardcore TV, ECW on TNN, ECW on Sci Fi ...), result, finish, debuts / last matches,
  dark matches, and match type. The match type list only shows stipulations that
  actually happened in NWA / WCW and ECW, with how many there are.

NAMES
  Ring names one person used are linked (Hollywood Hogan = Hulk Hogan, The Giant = Big
  Show, Cactus Jack = Mick Foley, Black Scorpion = Ric Flair ...). Names are matched
  whole, so "Bret Hart" is only Bret Hart - not the "The Hitman" who wrestled one WCW
  match in 1990. Small misspellings ("Bret Heart") find the closest wrestler.
  Singles vs tag matches are worked out from each result when the wiki doesn't say.

THE WRESTLER PANEL (right side)
  Record with win / loss / draw percentages, by era, matches per year, most-faced
  opponents (with win %), partners, and a record for every match type they had.
  Pick a match type (or type it, e.g. "Hulk Hogan steel cage") and the whole panel
  shows just those matches, compared with their overall record.

THE DATABASE
  The button at the top right shows what's in it: about 2,300 shows and 14,700
  matches - NWA/Crockett and WCW 1970-2001, ECW 1992-2001 and WWE's ECW 2005-2010 -
  from the Pro Wrestling Wiki. The wiki is the best free record of results but isn't
  complete - some early TV and many house shows have no page - so "never" and
  "debut" answers mean "in this database".
